# Applied AI & ML Capstone Project

An end-to-end data intelligence system built on the California Housing dataset — from
exploratory data analysis through to an LLM-powered explanation feature.

## Structure
- [Part 1](./Part1) — Data Cleaning, EDA & Preprocessing
- [Part 2](./Part2) — Regression & Classification Models
- [Part 3](./Part3) — Ensembles, Hyperparameter Tuning & Full ML Pipeline
- [Part 4](./Part4) — LLM-Powered Model Explanation Feature

Each Part has its own README, requirements.txt, and code files in its respective folder.
